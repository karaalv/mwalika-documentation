# Mwalika Stakeholder Meetings

This directory contains documentation and notes from stakeholder meetings related to the Mwalika project. These meetings are crucial for gathering input, feedback, and requirements from various stakeholders involved in or affected by the project.

## Contents

This directory has a flat structure, each file contains notes from a specific stakeholder meeting. Within each file is questions asked, answers given, and any action items or follow-ups identified during the meeting. The names and organisations of stakeholders are also documented for reference.
